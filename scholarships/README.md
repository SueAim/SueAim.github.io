# AIM NJ Scholarships

Public website: https://sueaim.github.io/scholarships/

Independent student resource for people working toward A&P, with New Jersey and applicable nationwide opportunities. Not an official AIM service.

The public directory distinguishes scholarships, tuition support, tools, exam fees, paid training and career pathways. Official provider pages control eligibility and application requirements.

No student accounts, server uploads, analytics or persistent student profiles are implemented. Browser filters, shortlist, writing workspace and application progress stay in page memory. Students can save/restore their own private work files locally.\n\nThe application workspace assembles a factual résumé, prepares provider-specific writing briefs and batch preparation packets, and supports copy, text downloads and browser print/PDF. ChatGPT is opened in the student’s own account; the website does not run an AI service, autofill third-party forms, submit applications or send email alerts. Optional dictation uses browser speech services; a downloadable daily calendar reminder is also available.

Automated maintenance checks maintained official sources, hides expired nonrecurring entries and confirmed missing links, retries hidden URLs for recovery, and publishes current public status. Date and payment details are not guessed from link reachability. Private working notes are not part of the current public project.
